# RTK 模式速查表

> 测竞品 / 写测试用例前先分清是哪种 RTK 模式，否则"制造 RTK 阴影"可能无效。

## 三种工作模式


| 模式                       | 校正源               | 卫星接收                    | 典型机型                                 |
| ------------------------ | ----------------- | ----------------------- | ------------------------------------ |
| **1+1 RTK / Local RTK**  | 用户家自建基站           | 外置 / 机身 GNSS 天线         | 老款 Navimow、九号传统 RTK 款                |
| **纯 Network RTK (nRTK)** | 4G/蜂窝 → 云端 CORS 网 | **机身内置 GNSS 天线**（默认无外置） | Navimow i2 AWD 系列（i206 默认）、Luba nRTK |
| **nRTK + 可选外置天线**        | 同上（4G 云端）         | 加装外置 GNSS 天线（连接到充电桩/机器） | 同上但用户购买了 Antenna Extension Kit       |


> Navimow 官方："Network RTK eliminates the need for traditional physical base stations"

---

## 如何制造"真正的 RTK 阴影"


| 模式                      | 有效操作                                          | 无效操作                  |
| ----------------------- | --------------------------------------------- | --------------------- |
| **1+1 RTK / Local RTK** | 盖基站（铝箔/铁罐）/ 拔基站电源 / 拔机身 RTK 天线                | —                     |
| **纯 nRTK**              | **断 4G/拔 SIM/飞行模式** + **铝箔/铁罐包机身顶部 GNSS 天线区** | ❌ 找树荫 ❌ 盖"基站"（根本没有基站） |
| **nRTK + 外置天线**         | 同上断 4G + **铝箔/铁罐包外置天线头**                      | 同上                    |


---

## 屏蔽材料


| 材料                 | 推荐度 | 备注               |
| ------------------ | --- | ---------------- |
| 厨房铝箔（≥ 3 层 + 胶带封缝） | ⭐⭐⭐ | 最便宜易得，缝 < 2cm 即可 |
| 不锈钢锅 / 饼干铁罐        | ⭐⭐  | 比天线大、能完全扣住       |
| 塑料 / 玻璃 / 纸盒       | ❌   | 完全无效（必须金属）       |


## 验收门槛

启动屏蔽后：APP RTK 状态从 FIX → FLOAT / SINGLE / NO FIX，**持续 ≥ 30 秒**才算阴影成立。否则用例作废、加强屏蔽。

---

## 关键判据（写测试用例时记得设计）


| 现象                       | 含义                                               |
| ------------------------ | ------------------------------------------------ |
| 大树下 nRTK 不掉信号            | 正常 — nRTK 校正源在云端不在天空                             |
| 7M-1 成功 + 7M-3（黑胶带遮双目）失败 | **双目视觉**是 RTK fallback 关键依赖                      |
| 7M-1 + 7M-3 都成功          | 不靠双目（RTK 弱信号 / 轮速 / IMU / 激光等其他）                 |
| 搬到无共视 B 区不重定位            | **激光机型把"桩 = 地图原点"**，无 LiDAR-based relocalization |
| 桩搬到 3m 外仅靠单目识别失败         | nRTK 桩识别走单目，作用距离上限 ~3m                           |
