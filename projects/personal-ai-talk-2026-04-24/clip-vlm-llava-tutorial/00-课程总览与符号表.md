# 第 0 章：课程总览与符号表

> 本章作用：在你打开任何一章之前，先把**整条主线的逻辑**和**关键符号**摆清楚。
> 这一章不需要懂任何细节，只需要 5 分钟翻一遍，知道"我们要去哪"。

---

## 一、整条主线一句话

> **CLIP 教会模型「看图认词」，LLaVA 教会模型「看图说话」。**
>
> 中间那一跳——「认词」如何变成「说话」——就是这门课要带你走完的路。

---

## 二、为什么这三件事要放在一起讲

CLIP、VLM、LLaVA 不是三个独立话题，而是同一条问题脉络上的三个里程碑：

| 时间 | 模型 | 解决的问题 | 留下的瓶颈 |
|---|---|---|---|
| 2021 | **CLIP** | 让视觉模型摆脱 ImageNet 1000 类的"封闭词表"，能识别**任意自然语言描述**的概念 | 只能"判别 / 检索"，不能"生成 / 对话" |
| 2022 | **BLIP / BLIP-2** | 在 CLIP 之上加生成能力，能给图配文（captioning） | 能描述图，但不会跟人**对话**、不会**跟随复杂指令** |
| 2023 | **LLaVA** | 把视觉特征接到 LLM，让模型**看图聊天**、**跟随多模态指令** | 幻觉、细粒度感知差、视频/3D 暂未解决 |

每一棒都在补前一棒的短板。理解了这条「问题→设计→新问题」的脉络，你就理解了整个 VLM 领域过去 5 年的演进逻辑。

---

## 三、四个阶段的学习重点

### 阶段一：对比学习预热（第 1-3 章）

> CLIP 的损失函数（InfoNCE）继承自对比学习。不补这块，CLIP 论文 Section 2.3 等于天书。

- **第 1 章**：建立"从贴标签到比远近"的世界观转变。
- **第 2 章**：吃透 InfoNCE 公式——它就是个 (N+1) 类 softmax 分类任务。
- **第 3 章**：通过 SimCLR 看对比学习的"最小完整范式"，吸收 3 个反直觉的工程细节（强 augmentation、projection head、large batch）。

**通过标准**：能用一句话回答「InfoNCE 在做什么、为什么要负样本、为什么 batch size 越大越好」。

### 阶段二：CLIP 精读（第 4-5 章）

> 主线核心。所有后续 VLM 模型都把 CLIP 当作视觉特征的提取器。

- **第 4 章**：双塔架构 + 对称损失 + N×N 矩阵图。
- **第 5 章**：4 亿对训练数据从哪来、prompt engineering 为什么是核心、零样本分类的数学机制、CLIP 的能力边界。

**通过标准**：能用 30 秒讲清「CLIP 为什么 work / 解决了什么问题 / 有什么 limitation」。

### 阶段三：从 CLIP 走向对话（第 6 章）

> 一节带过，建立 VLM 三大范式的分类学。

- **第 6 章**：CLIP 类（双编码器）、BLIP-2 类（编解码器 + Q-Former）、LLaVA 类（LLM-based）三种范式的取舍。

**通过标准**：能在听到一个新 VLM 时，秒判断它属于哪类、强在哪、弱在哪。

### 阶段四：LLaVA 精读 + 贯通（第 7-9 章）

> 当前 VLM 的事实标准。所有开源多模态助手（MiniGPT-4、InternVL、Qwen-VL）基本都受 LLaVA 启发。

- **第 7 章**：极简架构 + GPT-4 造数据这两个杀手级设计。
- **第 8 章**：两阶段训练 + LLaVA-1.5 / NeXT 的关键升级。
- **第 9 章**：把 CLIP→LLaVA 的设计哲学提炼成 3 个跃迁。

**通过标准**：能解释为什么 LLaVA 用 158K 数据 + 极简投影器就达到了惊人效果，反观 CLIP 却需要 4 亿对数据。

## 四、阅读策略（三件事必须做）

### 1. 论文按这个顺序读，不要陷数学

1. 读 Abstract：知道说了什么。
2. 读 Introduction：知道为什么重要。
3. 看 Figure 1/2/3 + caption：抓核心思想。
4. 跳读 Method：知道怎么做，**不要陷数学**。
5. 看 Results 主表：知道效果。

每篇控制在 20-30 分钟。

### 2. 读完一章，强迫自己回答 3 个问题

1. **它为什么 work？**（设计的关键洞察是什么）
2. **它解决了什么问题？前人怎么做的？**（在历史中的定位）
3. **它有什么 limitation？**（边界在哪）

这三个问题如果都能 30 秒答出来，就说明这一节你能讲给同事听。

### 3. 不懂时怎么办（按这个顺序）

- 第一选择：再看官方博客 / 图解材料。
- 第二选择：看权威视频讲解。
- 第三选择：读论文 Abstract + Figure。
- 第四选择：把具体卡住的句子贴出来问我。

## 五、完整符号表

> 全教程统一遵守这套符号。出现新符号时，每章会在该处再次解释。

### 通用

| 符号 | 含义 |
|---|---|
| $\mathbf{x}$ | 图像（image） |
| $\mathbf{t}$ | 文本（text，如 caption / 指令） |
| $\mathbf{v}$ | 视觉特征向量（visual feature） |
| $N$ | batch size |
| $D$ | 嵌入向量维度（embedding dimension），如 512 / 768 |
| $\theta$ | 神经网络参数 |

### 编码器与表征

| 符号 | 含义 |
|---|---|
| $f_I(\cdot)$ | 图像编码器（image encoder），如 ResNet / ViT |
| $f_T(\cdot)$ | 文本编码器（text encoder），通常是 Transformer |
| $g(\cdot)$ | projection head（投影头），SimCLR / CLIP 都用 |
| $\mathbf{I}_i \in \mathbb{R}^D$ | 第 $i$ 张图的 L2 归一化嵌入 |
| $\mathbf{T}_i \in \mathbb{R}^D$ | 第 $i$ 段文本的 L2 归一化嵌入 |

### 对比学习核心

| 符号 | 含义 |
|---|---|
| $q$ | query 向量（anchor 视图的表征） |
| $k^+$ | positive key（同一物体另一视图） |
| $k_i$ | 第 $i$ 个 key 候选（包含 1 个正例和 N 个负例） |
| $\text{sim}(\mathbf{u}, \mathbf{v}) = \frac{\mathbf{u}^\top \mathbf{v}}{\|\mathbf{u}\|\|\mathbf{v}\|}$ | 余弦相似度 |
| $\tau$ | temperature 温度系数 |
| $\mathcal{L}_{\text{InfoNCE}}$ | InfoNCE 损失 |

### CLIP 专属

| 符号 | 含义 |
|---|---|
| $\mathbf{S} \in \mathbb{R}^{N \times N}$ | 一个 batch 内 $N$ 张图与 $N$ 段文本的相似度矩阵 |
| $\mathcal{L}_{\text{i2t}}$ | 图→文方向的 InfoNCE 损失（image-to-text） |
| $\mathcal{L}_{\text{t2i}}$ | 文→图方向的 InfoNCE 损失（text-to-image） |
| $\mathcal{L}_{\text{CLIP}}$ | $\frac{1}{2}(\mathcal{L}_{\text{i2t}} + \mathcal{L}_{\text{t2i}})$，对称损失 |

### LLaVA 专属

| 符号 | 含义 |
|---|---|
| $\mathbf{H}_v$ | 视觉特征（CLIP-ViT 输出的 patch tokens） |
| $W$ | linear projector / MLP 投影器（LLaVA 唯一可训练的连接层） |
| $\mathbf{Z}_v = W \cdot \mathbf{H}_v$ | 投影后的视觉 token，与 LLM word embedding 同维度 |
| $\mathbf{X}_q$ | 文本指令（question） |
| $\mathbf{X}_a$ | 模型回答（answer） |
