# FAQ-01：训练 vs 采样 —— 扩散模型最大的认知断层

> **建立时间**：2026-05-12（学完 00–07 与中场总结之后）
>
> **本笔记目的**：彻底打通"训练时一直在做图生图、可推理时却凭空生图"这个困惑。
>
> 这是几乎每个学扩散模型的人都会卡的认知断层。理解了它，文生图 / 图生图 / inpainting / ControlNet 的全部用法都会一并打开。

---

## 一、原问题（学习者卡点）

> **问 1**："输入'加噪图 + 时间步'，输出'加进去的噪声残差'。这句话不理解，输出为什么是噪声残差，怎么理解？"
>
> **问 2**：解释完之后，"那 这个模型可以做什么？如果我输入我的一张照片，它会输出什么？"
>
> **问 3**："我还是没有理解，如果是从虚空开始，那输入是什么？文字，然后直接输出一张图？前面介绍这个网络，似乎一直是图生图啊？加噪声，又去噪。"

最后这句话**精准命中了所有人的认知断层**：训练阶段看起来在做"图 → 加噪 → 去噪 → 图"，那为什么推理时能"凭空生图"？

---

## 二、卡点的根本原因：把"训练"和"采样"混成了一件事

扩散模型有**两个完全独立的阶段**，输入输出完全不同：


| 阶段         | 干什么             | 输入                 | 输出                               | 需要图吗？      |
| ---------- | --------------- | ------------------ | -------------------------------- | ---------- |
| **训练**     | 让网络学"自然图像的知识"   | 真实图 + 自己加的噪声       | 预测刚才加的噪声 $\boldsymbol{\epsilon}$ | ✅ 需要海量真实图  |
| **采样（推理）** | 让网络**用知识凭空生成图** | **一团纯随机噪声**（randn） | **一张全新的图**                       | ❌ 完全不需要任何图 |


> **关键认知**：训练阶段的"图"只是用来产生"答案标签"的副产品。
>
> **训练完成后，这些图就完成了使命**。采样时网络根本不需要图。

---

## 三、训练完成后，网络到底学到了什么？

不是 "图 A → 图 B" 的某种映射，
而是 **"自然图像分布的内在知识"**。

具体说，网络掌握了一种能力：

> 给我任意一个张量 $\mathbf{x}_t$，我能告诉你"如果你把它当作某张真实图加噪 $t$ 步而来，那加进去的噪声大概长什么样"。

这个能力一旦学会，就和具体哪张训练图无关了。它是关于**整个真实图像分布**的知识。

---

## 四、采样阶段的真实流程（重点）

伪代码如下：

```python
# === 推理阶段（生成一张新图，无条件版本）===

# 第 0 步：从虚空开始 —— 不需要任何输入图！
x_T = torch.randn(3, 256, 256)   # 真·凭空采样一团标准高斯噪声

# 反复"减残差"
for t in range(T, 0, -1):
    eps_pred = network(x_t, t)                # 网络预测一团噪声
    x_{t-1} = (1 / sqrt(alpha_t)) * (
        x_t - (1 - alpha_t) / sqrt(1 - alpha_bar_t) * eps_pred
    )
    x_{t-1} += sigma_t * torch.randn_like(x_t)   # 一点抖动
    # ↑ x_{t-1} 比 x_t 略微"更有结构"

# 最终
x_0 = ...   # 一张凝结出来的全新图（比如一张全新的人脸）
```

**真正的"输入"只有两样**：

1. `torch.randn(3, 256, 256)` ← **凭空采的随机张量**
2. 时间步序列 `t = T, T-1, ..., 1`

**没有任何照片！**

---

## 五、为什么 `randn()` 出来的起点可以用？

回到第 2 章 nice property：当 $T$ 足够大时

$$
\mathbf{x}_T = \sqrt{\bar\alpha_T}\mathbf{x}_0 + \sqrt{1-\bar\alpha_T}\boldsymbol{\epsilon} \approx \boldsymbol{\epsilon} \sim \mathcal{N}(\mathbf{0}, \mathbf{I})
$$

因为 $\bar\alpha_T \to 0$，所以**任意真实图加噪 $T$ 步后都长得像标准高斯噪声**。

反过来：

> `torch.randn(...)` 采出来的标准高斯张量，
> 与"某张未知真实图加噪 $T$ 步"在统计上**完全不可区分**。

网络看到它就把它当作"某张图加噪而来"，然后**反推回去**。

每次 randn 起点不同 → 反推路径不同 → **生成的图不同**。这就是扩散模型生成多样化图的根源。

---

## 六、那"文字"是怎么进来的？

刚才讲的是**无条件生成**：randn → 反推 → 一张随机内容的图。

如果想生成**指定内容**（比如"一只戴帽子的猫"），就把网络从

$$
\boldsymbol{\epsilon}_\theta(\mathbf{x}_t, t)
$$

升级成

$$
\boldsymbol{\epsilon}_\theta(\mathbf{x}_t, t, \mathbf{c})
$$

—— **多接一个条件输入** $\mathbf{c}$。

$\mathbf{c}$ 可以是：

- 文本嵌入（CLIP / T5 编码后的向量）→ 文生图
- 另一张图的特征 → 图生图、风格迁移
- 边缘图、姿态、深度图 → ControlNet
- 类标签 → class-conditional generation

### 文生图（DALL-E / Stable Diffusion）的实际流程

```python
# 1. 用户输入文字
prompt = "a cat wearing a hat"

# 2. 文本编码器把文字变成向量
text_emb = text_encoder(prompt)              # 例 (77, 768)

# 3. 真·凭空采一个起点（与无条件生成一样！）
x_T = torch.randn(3, 256, 256)

# 4. 反复减残差，但每一步都把文本一并喂给网络
for t in range(T, 0, -1):
    eps_pred = network(x_t, t, text_emb)     # ← 文本影响每一步去噪方向
    x_{t-1} = update(x_t, eps_pred)

# 5. 凝结出一张和文字描述符合的图
return x_0
```

**关键**：起点 `x_T` **仍然是 randn 出来的纯噪声**！文字不是"输入图"，而是**告诉网络往哪个方向游**。

> - **randn** 决定"图的具体长相"（随机性）
> - **文字** 决定"图的内容方向"（约束）
> - **训练好的网络** 决定"图的真实感"（手艺）

## 七、雕塑家比喻（彻底打通直觉）

> **训练**：雕塑家研究了 1 亿件大师作品，**学会了"什么叫一件好雕塑"**——这就是自然图像分布的知识。
>
> **采样**：你给他一块**形状随机的大理石**（randn 噪声），他不需要别的输入图，直接凿。
>
> - 凿什么？凿成"在他脑中的好雕塑分布里、距离这块石头当前形状最近的那个"。
> - 每次给的石头形状不一样，凿出来的雕塑就不一样。
>
> **文生图**：你顺手给他一句话："凿一只戴帽子的猫。" 他依然从那块石头开始凿，但**凿的方向被你的话约束**了。


| 雕塑过程      | 扩散模型                                | 提供什么 |
| --------- | ----------------------------------- | ---- |
| 大理石（随机形状） | randn 起点 $\mathbf{x}_T$             | 多样性  |
| 你的描述      | 文本/图像/mask 条件 $\mathbf{c}$          | 方向   |
| 雕塑家的手艺    | 训练好的 $\boldsymbol{\epsilon}_\theta$ | 真实感  |

## 八、img2img 是怎么用照片的？—— 改变"起点"

**img2img**（输入照片 + 文字，得到照片的变体）：本质就是**不从纯噪声开始凿，而是从"你的照片加了一半噪声"开始凿**。

```python
# 用户给一张照片 + 文字
your_photo = load("自拍.jpg")
prompt = "梵高风格"

# 不再 randn 一个纯噪声起点，而是把照片加噪到中间状态
t_start = T // 2                              # 比如 500 步
x_500 = (sqrt(alpha_bar[500]) * your_photo
         + sqrt(1 - alpha_bar[500]) * torch.randn_like(your_photo))
# ↑ nice property：把你照片加噪到 500 步那个状态

# 然后从 t_start 开始去噪（不是从 T，而是从中间）
text_emb = text_encoder(prompt)
for t in range(t_start, 0, -1):
    eps_pred = network(x_t, t, text_emb)
    x_{t-1} = update(x_t, eps_pred)

return x_0   # 你照片的"梵高风格变体"
```

**精髓**：

- 起点不是纯随机噪声，而是"**照片的部分加噪状态**" → 保留了照片的**结构信息**（构图、姿态）
- 网络去噪过程中又被 prompt 拉向"梵高风格"
- 最终：**结构来自照片，风格来自文字** ✓

img2img 的"强度"（0.0–1.0）就是控制 `t_start` 的位置：


| 强度  | 起点                 | 效果              |
| --- | ------------------ | --------------- |
| 0.1 | $\mathbf{x}_{100}$ | 几乎和原图一样，只是细节微调  |
| 0.5 | $\mathbf{x}_{500}$ | 保留构图，明显改变风格     |
| 1.0 | $\mathbf{x}_T$     | 等于纯文生图，照片完全失去作用 |

## 九、所有用法的统一图

```
                          采样过程的"起点"决定一切
                                     │
                ┌────────────────────┼────────────────────┐
                ↓                    ↓                    ↓

         randn() 纯噪声        照片加噪到 t=500       照片挖空一块 + randn
             ↓                       ↓                        ↓
       【文生图】                【图生图】                【inpainting】
       prompt "猫戴帽"         prompt "梵高风"           prompt "在月球上"
             ↓                       ↓                        ↓
       一只戴帽的猫            照片的梵高风变体          人物站在月球上
```

**所有这些工作流，用的是同一个训练好的网络** $\boldsymbol{\epsilon}_\theta(\mathbf{x}_t, t, \mathbf{c})$。

**变的只是采样时的"起点"和"条件输入"**。

## 十、回到原问题：那张照片输入会输出什么？

**直接喂干净的照片给** $\boldsymbol{\epsilon}_\theta(\mathbf{x}_t, t)$ —— 输出是垃圾。

理由：训练时网络见过的输入都是"加过噪的图"，干净照片是 OOD（分布外）输入，网络的输出语法上合法但语义上无意义。

但通过下面这些**正确的工作流**，照片可以发挥不同作用：


| 工作流                  | 照片扮演什么                  | 得到什么                |
| -------------------- | ----------------------- | ------------------- |
| 无条件生成                | 不参与                     | 随机的逼真图              |
| 文生图                  | 不参与，给文本                 | 符合文本描述的图            |
| **图生图（SDEdit）**      | 起点（先加部分噪声，再去噪）          | 照片的**变体**（保留结构，换风格） |
| **图像修复（inpainting）** | 起点 + mask               | 把挖掉的部分补出来           |
| **超分 / 上色 / 去模糊**    | 低分辨率/灰度/模糊作为条件          | 高清 / 彩色 / 清晰版       |
| **ControlNet**       | 提取的"骨架"（边缘、姿态、深度）作为控制信号 | 全新图，保留原图结构          |


---

## 十一、原问题的最终澄清

> "前面介绍这个网络，似乎一直是图生图啊？加噪声，又去噪。"

**那是"训练阶段"的视角**。训练时为了产生监督信号，必须先有真实图加噪、再让网络反推噪声。

**训练好之后，那些图就用不上了**。采样时只需要：

- 凭空 `randn()` 一个起点
- （可选）给点条件信息（文本 / 图像 / mask）
- 反复"减残差"

—— **这才是扩散模型的"使用方式"**。

---

## 十二、一句话核心

> **训练阶段**：让网络学到"自然图像分布的知识"。
>
> **采样阶段**：从一坨随机噪声出发，靠这份知识 + 一些指挥（文字/图像/mask），反复"减残差"，凝结出一张全新的图。
>
> **照片不是被加工对象，而是可选的"指挥棒"**——决定从哪个起点开始凿、往哪个方向凿，但不决定"凿这个动作本身"。

---

## 十三、自检

下面三题心里默答一遍：

1. **训练完成后，硬盘上保存的是什么？是那 1 亿张训练图吗？**
  👉 答案 只是网络参数 $\theta$（一个文件，几百 MB 到几 GB）。训练图一旦训练完成就可以全部删掉，对推理毫无影响。网络参数里"内化"了图像分布的知识。
2. **生成"猫戴帽"和"狗戴帽"，哪个环节的输入不一样？**
  👉 答案 只有 `text_emb` 不一样（文本嵌入向量）。`x_T = randn()` 起点也可以一样，但即使起点一样，文本不同会让每一步去噪方向不同，最终凝结出不同的图。
3. **img2img 强度 = 0.5 和强度 = 1.0 在数学上的差别是什么？**
  👉 答案 差别在 **采样起点的 t**：
  - 强度 0.5：起点是 $\mathbf{x}*{500} = \sqrt{\bar\alpha*{500}}\mathbf{x}*0 + \sqrt{1-\bar\alpha*{500}}\boldsymbol{\epsilon}$，保留了一半原图信号。
  - 强度 1.0：起点是 $\mathbf{x}_T \approx \boldsymbol{\epsilon}$，原图信号完全消失，等价于纯文生图。
   强度越高，原图影响越小，最终输出越偏离原图。
