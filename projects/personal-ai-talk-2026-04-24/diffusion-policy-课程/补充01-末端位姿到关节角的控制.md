# 🔧 补充 01：末端位姿指令是怎么变成关节角的？（mid-level controller / QP 微分逆运动学）

> 触发来源：第 0 课/上一轮问答里出现过一句——
> *"一个 mid-level controller 把『末端位姿指令』通过微分逆运动学（QP 求解）转成『关节角速度』，再积分成关节角；顺便加约束：碰撞规避、关节限位、安全区。"*
> 这句来自 Diffusion Policy 论文 **附录 D**。
> 学习目标：你是做 SLAM/定位的，本篇把这套机器人控制术语**全部翻译成你已经熟的优化/状态估计语言**（雅可比、伪逆、LM 阻尼、gauge freedom、分频架构），让你遇到 `q̇=J⁺ẋ`、DLS、零空间时能秒对应。
> 关系定位：这块属于 **policy 的输出之后**——Diffusion Policy 吐出末端位姿，这个 controller 负责把它落到电机。它本身不是 diffusion 的一部分，但不懂它就不知道"动作"最后怎么执行。

---

## 一、一句话结论（先给地图）

> 🎯 **mid-level controller = 一个「带不等式约束的加权最小二乘」，每个控制步求解一次。**
> - 决策变量：关节角速度 `q̇`（不是地图点，不是位姿）
> - 雅可比：运动学雅可比 `J(q) = ∂f/∂q`（不是重投影雅可比，但角色完全一样）
> - 目标：让 `J(q)·q̇` 逼近 policy 要的末端速度
> - 约束：关节限位、速度限位、碰撞、安全区
> - 正则：DLS 阻尼 = 你在 Ceres/g2o 里调的那个 LM 的 `λ`

把它和 SLAM 对齐：**就是把 BA 里的「重投影雅可比 + 高斯牛顿 + LM 阻尼 + 边缘化先验」整套搬过来，只是状态从「地图点/位姿」换成「关节角速度」。**

## 二、正运动学 vs 逆运动学

| | 定义 | SLAM 类比 |
|---|---|---|
| **正运动学 FK** | 给关节角 `q ∈ ℝⁿ`，算末端位姿 `x = f(q) ∈ SE(3)`。`f` 由连杆几何唯一确定，显式可微 | 相机投影 `project(landmark, pose)`：给状态出观测，显式唯一 |
| **逆运动学 IK** | 给期望位姿 `x*`，反解 `q` 使 `f(q)=x*`。反解非线性方程组 | PnP / 三角化的反解：已知观测求状态，可能多解/无解 |

### 2.1 解析 IK 为什么难

直接写闭式解只在自由度少、几何特殊（球形手腕）时可行，再复杂就不行。三个难点和 SLAM 反问题里的病态情形同构：

- **多解**：同一末端位姿可由多组关节角达到（肘上/肘下、手腕翻转）→ 对应 PnP/P3P 的多解
- **无解**：目标在工作空间外 → 对应观测落在几何不可能位置
- **奇异（singularity）**：某些 `q` 处雅可比降秩，解灵敏度爆炸 → 对应退化运动/不可观方向（见第六节）

> 💡 解决思路：**把"位姿级的非线性反问题"降到"速度级的线性反问题"**，就能用伪逆/最小二乘逐步迭代，绕开闭式解的困难。这就是「微分逆运动学」。

---

## 三、微分逆运动学：核心三步

### 3.1 第一步：对 FK 求导得到线性关系

对 `x = f(q)` 求时间导，链式法则：

$$
\dot{x} = \frac{\partial f}{\partial q}\,\dot{q} = J(q)\,\dot{q}
$$

- `J(q) = ∂f/∂q` 是 `m × n` 的**运动学雅可比**：`m` = 末端任务维度（位置 3 + 姿态 3 = 6），`n` = 关节数
- `ẋ` = 末端空间速度（twist：线速度 + 角速度），`q̇` = 关节角速度
- **关键**：`q` 固定那一刻，这是关于 `q̇` 的**线性方程**

> SLAM 类比：这和 BA 里把残差对状态线性化得到 `J δx = −r` 是同一个动作。`J(q)` 之于关节 = 测量雅可比 `∂z/∂x` 之于状态。

### 3.2 第二步：反解 q̇（伪逆 / 最小范数解）

冗余臂（`n > m`，如 7-DoF 臂控 6-DoF 末端）下方程欠定，取**最小范数解**：

$$
\dot{q} = J^{+}\dot{x}, \qquad J^{+} = J^\top (J J^\top)^{-1}\ \text{(右伪逆，胖矩阵 } n>m\text{)}
$$

`J⁺` 就是 Moore-Penrose 伪逆，给出所有满足 `J q̇ = ẋ` 的解里 `‖q̇‖` 最小那个。

> SLAM 类比：就是你熟的最小二乘正规方程解 / 高斯牛顿步。`J⁺ = (JᵀJ)⁻¹Jᵀ`（超定/瘦）或 `Jᵀ(JJᵀ)⁻¹`（欠定/胖）。SVD 视角 `J⁺ = VΣ⁺Uᵀ`，和你做退化分析看奇异值是同一套。

### 3.3 第三步：欧拉积分回关节角

$$
q_{k+1} = q_k + \dot{q}\cdot\Delta t
$$

> SLAM 类比：状态传播/增量更新。关节空间是平坦 `ℝⁿ` 直接加；若在 `SE(3)` 上更新末端就要用 retract/`⊞`（box-plus）和 `log/exp` map——和你流形上做状态更新一模一样。末端姿态误差 `ẋ` 的旋转部分本身就是 `log(R*·R_currᵀ)` 这类对数映射算的。

## 四、阻尼最小二乘 DLS = LM 阻尼（你最熟的那个）

纯伪逆在接近奇异（`J` 某奇异值 `σ → 0`）时 `q̇` 会爆炸（`1/σ → ∞`）。**阻尼最小二乘（Damped Least Squares, DLS）**加阻尼项稳住：

$$
\dot{q} = J^\top (J J^\top + \lambda^2 I)^{-1}\dot{x} = (J^\top J + \lambda^2 I)^{-1} J^\top \dot{x}
$$

SVD 展开后每个方向的增益从 `1/σᵢ` 变成 `σᵢ/(σᵢ² + λ²)`：`σ` 大时≈`1/σ`（不影响正常方向），`σ → 0` 时趋于 0 而非发散。

> 🎯 **这就是 SLAM 里的 LM 阻尼。** DLS 又名 Levenberg-Marquardt 方法（Wampler 1986、Nakamura & Hanafusa 1986 最早用到 IK）。你在 Ceres/g2o 里调的 `λ`（解 `(H + λI)δx = b`）和这里的 `λ²` 是同一个东西：病态/奇异处用阻尼把解从"最小二乘"拉向"梯度下降"，牺牲一点精度换数值稳定。

## 五、为什么非要写成 QP

伪逆/DLS 能给最小范数解，但**塞不进不等式约束**（关节不能超限、不能撞桌子）。`q̇=J⁺ẋ` 是无约束闭式解，没有任何机制阻止它算出"会撞桌子"或"超关节上限"的 `q̇`。

把同一个最小二乘目标写成 **Quadratic Program**，就能在保持跟踪目标的同时附加线性不等式约束。每个控制步求解：

$$
\begin{aligned}
\min_{\dot{q}}\quad & \tfrac{1}{2}\|J(q)\dot{q} - \dot{x}_\text{des}\|_W^2 + \tfrac{1}{2}\lambda\|\dot{q}\|^2 \quad\text{(主任务 + DLS 正则)}\\
\text{s.t.}\quad & \dot{q}_\min \le \dot{q} \le \dot{q}_\max \quad\text{(速度限位)}\\
& (q_\min - q)/\Delta t \le \dot{q} \le (q_\max - q)/\Delta t \quad\text{(关节位置限位转速度界)}\\
& G(q)\dot{q} \le h(q) \quad\text{(碰撞 / 安全区)}
\end{aligned}
$$

- 目标第一项 = 末端速度跟踪误差，`W` 是任务权重（置信度/优先级）
- 目标第二项 = `λ‖q̇‖²` 正则，作用同第四节 DLS 阻尼
- 关节位置限位用"当前角到上下限还剩多少 / Δt"换算成本步允许速度区间——把位置约束降到速度级的标准技巧

> SLAM 类比：目标函数就是你熟的 `½‖J δx − r‖²_Σ⁻¹ + 正则`；`W` 对应信息矩阵 `Σ⁻¹` 加权；约束部分是 BA 里通常没有、但概念上就是 box-constrained least squares。

### 5.1 碰撞 / 安全区怎么变成约束

设最近距离 `d(q)`（机器人某 geom 到障碍/桌面），一阶展开 `ḋ ≈ (∂d/∂q)q̇`，常用两种写法：

- 朴素线性化：`d(q) + (∂d/∂q)q̇·Δt ≥ d_safe`
- **Control Barrier Function (CBF)**：`(∂d/∂q)q̇ ≥ −α(d − d_safe)`，`α(·)` 是 class-K 函数。它保证安全集 `{q : d(q) ≥ d_safe}` 的**前向不变性**——一旦在安全集内就出不去，且离边界越近允许的逼近速度越小

> SLAM 类比：`∂d/∂q` 就是"距离这个标量观测"对状态的雅可比，和你给任何残差求 `∂z/∂x` 没区别；CBF 的 `α` 项相当于一个软边界障碍。

## 六、零空间与冗余自由度（= 你熟的 gauge freedom）

7-DoF 臂控 6-DoF 末端，多出 1 个自由度——这 1 维就是雅可比的**零空间 null(J)**：在里面动关节，末端不动。通解：

$$
\dot{q} = \underbrace{J^{+}\dot{x}}_{\text{主任务：达成末端速度}} + \underbrace{(I - J^{+}J)\dot{q}_0}_{\text{零空间：不影响末端}}
$$

`(I − J⁺J)` 是到 `null(J)` 的正交投影矩阵：任何 `q̇₀` 经它投影后乘 `J` 都为零，所以加上去不改变末端速度，只在"末端不动的自由方向"上动关节。可以选 `q̇₀ = −k ∂H/∂q` 让零空间运动去做次级目标（保持舒适姿态、远离关节限位）。

> 🎯 **这就是你做规范分析时的 gauge freedom / 不可观零空间。** 单目 SLAM 的 7 维 gauge（尺度 + `SE(3)`）、纯视觉的不可观方向，都是"沿这些方向改状态不改变观测/残差"。`(I − J⁺J)` 就是把任意更新投影到"不影响主目标子空间"的投影算子。在零空间加次级目标 = 对 gauge/不可观方向施加 prior / 正则 / gauge fixing（你给尺度加先验、给重力方向加约束就是这个）。

## 七、分层控制与频率（= 你熟的前端/后端分频）

整个系统是分频三层级联：

| 层 | 频率 | 干什么 | SLAM 类比 |
|---|---|---|---|
| **policy** | ~10 Hz | Diffusion Policy 出期望末端位姿序列（推理重，任务级决策不需高频） | 后端 BA/优化（~10 Hz，给目标） |
| **mid-level QP IK** | ~1 kHz 量级 | 本篇主角，末端指令→关节速度/位置 + 约束 | 中间衔接层 |
| **joint-level controller** | 最快 | 电机级 PID/力矩环，跟踪关节位置 | 前端高频跟踪（IMU 预积分 ~200Hz+） |

> SLAM 类比：典型的**分频/松紧耦合**架构——慢层给目标、快层做跟踪，中间用积分/插值衔接。解耦复杂度、各层用合适频率和模型。

## 八、SLAM/优化 类比对照表（一页速查）

| manipulation 概念 | SLAM / 优化 对应 | 共同数学本质 |
|---|---|---|
| 运动学雅可比 `J(q)=∂f/∂q` | 测量/重投影雅可比 `∂z/∂x` | 输出对状态的一阶偏导 |
| `ẋ = J q̇` 局部线性化 | BA 残差线性化 `J δx = −r` | 非线性问题就地线性化 |
| 伪逆解 `q̇=J⁺ẋ` | 高斯牛顿步 / 正规方程解 | `J⁺=Jᵀ(JJᵀ)⁻¹` 或 `(JᵀJ)⁻¹Jᵀ` |
| SVD 看 `J` 奇异值 | 退化/可观性分析看奇异值 | `J⁺=VΣ⁺Uᵀ` |
| DLS 阻尼 `λ²I` | LM 阻尼 `μI` | `(JᵀJ+λ²I)⁻¹`，病态时稳解 |
| 奇异点 `σ→0` | 不可观/退化方向 | 某方向增益 `1/σ` 爆炸 |
| 零空间投影 `(I−J⁺J)` | gauge freedom / 不可观零空间 | 不改变主目标的自由子空间 |
| 零空间次级目标 | gauge fixing / 加 prior / 正则 | 在不可观方向注入偏好 |
| QP 不等式约束 | box-constrained / 带约束 LS | 最小二乘 + 线性硬约束 |
| 任务权重 `W` | 信息矩阵 `Σ⁻¹` 加权 | 各项按置信度加权 |
| CBF 安全约束 | 不等式约束一阶线性化 / barrier | `∂d/∂q` 是距离观测的雅可比 |
| 欧拉积分 `q̇→q` | 状态传播 / 流形 retract `⊞` | 增量更新（`ℝⁿ` 直加，`SE(3)` 用 exp） |
| 分层 policy/mid/joint | 前端/后端、松紧耦合分频 | 慢层给目标、快层做跟踪 |
