# Diffusion Policy · 论文精读课程

> 论文：**Diffusion Policy: Visuomotor Policy Learning via Action Diffusion**
> （arXiv: 2303.04137v5, Chi et al., RSS 2023 扩展版 2024）
> 教学方式：每节课讲一个核心概念，配课后小问，循序渐进。先从优化视角切入 diffusion，把陌生的生成模型概念翻译成"梯度场 + 迭代优化"的语言。

## 学员背景校准

| 维度 | 起点 | 讲法策略 |
|---|---|---|
| 优化 / 梯度 / 概率 | 强 | 直接用，作为切入角（diffusion 本质是学一个梯度场） |
| 坐标系 / 位姿 / 控制 | 强 | 末端位姿、IK、receding horizon 快讲 |
| 生成模型（DDPM/score/Langevin） | 弱 | 重点展开区，用"带噪梯度下降"类比，不堆推导 |
| 模仿学习 / behavior cloning | 弱 | 从"为什么回归会失败"讲起，建立动机 |
