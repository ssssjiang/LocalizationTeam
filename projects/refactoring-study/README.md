# 《重构（第 2 版）》精读笔记 · C++ 视角

> Martin Fowler《Refactoring: Improving the Design of Existing Code》(2nd ed.)
> 原书示例用 JavaScript，本笔记用 **C++ 最小示例** 辅助理解。
> 在线书源：<https://book-refactoring2.ifmicro.com/>

## 学习目标

- **实战决策**：记住「何时用哪个手法 + 决策规则」，形成 C++ 肌肉记忆。
- **体系认知**：理解重构的整套思想与取舍，而不只是手法清单。

## 学习流程

每章的完整操作流程（抓原文 → 起草三层笔记 → 多子代理 review → 汇总修订 → 收尾）与踩坑记录见 [`学习流程.md`](./学习流程.md)。

## 笔记体例（每章一份 md）

每份笔记按三层组织，便于「最短时间抓重点、又不丢关键细节」：

1. **一页纸决策速查**：结论先行，可日常翻阅的清单/口诀。
2. **分节要点**：对应原书小节，保留关键细节与原书点名的手法。
3. **C++ 示例**：原书 JS 例子的 C++ 对照，或概念级最小片段。

> 纯理念章（如第 2 章）C++ 示例偏「概念级」；进入手法目录（第 6~12 章）后给「重构前 → 重构后」完整 C++ 对照。
