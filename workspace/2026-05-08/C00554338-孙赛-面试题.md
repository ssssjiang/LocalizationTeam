## 一、针对项目提问

### A. 比亚迪：闭环仿真 + 4DGS（2025.08–至今）

#### Q1. 在 StreetGaussian / OmniRe 这类框架里，用 SMPL 驱动行人高斯，你会把哪些量当作优化变量？如何将 SMPL 顶点/关节与 3D Gaussian（位置、协方差、不透明度、SH 系数）联系起来？

**参考答案要点**：SMPL 给出人体姿态 \(\theta\)、形状 \(\beta\) 与全局位姿；常见做法是把每个高斯绑定在 SMPL 表面局部坐标（或按顶点/三角形分区），用 blend shape / skinning 把 canonical 空间的高斯变换到当前帧；优化变量可以是每帧 SMPL 参数 + 每高斯的 residual（偏移、尺度）或仅微调 appearance。需区分「几何随 SMPL 刚体/近似刚体变化」与「衣物等非 SMPL 区域」是否额外加 deformable 分支。

#### Q2. PVG（动态高斯）与 Deformable 3DGS 在「骑行人」这类柔性物体上各适合解决什么问题？你会如何选或组合？

**参考答案要点**：PVG 类强调随时间变化的 Gaussian（速度场、生命周期），适合规律运动与显式时间建模；Deformable 强调 canonical 空间 + 形变场 \(M(x,t)\)。骑行人大变形 + 与车体交互，单一刚性模板不够；可组合：人体骨架/粗略 SMPL + 局部形变场或额外动态高斯吸附在非刚性区域；评估看渲染质量、时间一致性与仿真闭环里的可控性（是否需要物理合理运动）。

#### Q3. 闭环仿真「渲染产线」里，除了画质，工程上你最关心哪些指标？如何优化性能与内存？

**参考答案要点**：延迟、吞吐（FPS / 每帧 ms）、GPU 显存峰值、与 ego pose / 传感器同步的时间戳语义；优化手段：LOD、剔除视野外高斯、culling、紧凑存储（SH 阶数、fp16）、异步拷贝、实例化重复物体、缓存静态场景动态物体分层更新。可追问是否做过 profiling（Nsight）、瓶颈在 rasterization 还是排序。

### B. 比亚迪：众包建图 + BEV（2024.08–2025.08）

#### Q4. 单趟 BEV 重建与多趟聚合：误差主要来自哪里？聚合时用什么对齐（pose / loop / global BA）？如何避免「叠偏」？

**参考答案要点**：单趟累积漂移、高度估计不稳、跨趟光照与传感器标定差；多趟靠全局位姿图 + 闭环 + 可能的语义/BEV feature 匹配；约束上要统一坐标系（往往 RTK/地图锚点）、robust kernel 压制错误闭环、分层优化（先 pose 再稠密/BEV）。追问 QT 工具里人工干预闭环的具体流程。

#### Q5. 众包地图更新已量产：更新触发条件是什么（轨迹重合度、时间版本、区域 lock）？冲突解决策略（新老几何以谁为准、是否保留多版本）？

**参考答案要点**：期望听到「变更检测 / diff / 置信度 / 运营策略」之一；量产通常有时序版本、灰度区域、回滚；技术上可能 tile 级版本号 + 增量 patch + 一致性校验。没有细节也可追问设计思路。

### C. 地平线：融合定位 + 自动标注（2021–2024）

#### Q6. Camera + IMU + 轮速 + LiDAR + RTK 紧耦合：状态向量通常包含哪些？RTK 与视觉/LiDAR 观测各怎么进因子图或滤波器？

**参考答案要点**：状态常含 IMU bias、车速尺度因子（若有）、位姿/速度；GNSS 位置（及可选双天线航向）作全局锚；视觉重投影或点到线面；LiDAR scan matching；轮速非完整约束；紧耦合统一优化需注意异步时间戳对齐与外参标定。追问「松耦合 vs 紧耦合」在该项目中的取舍。

#### Q7. 高精地图匹配：感知重建矢量与 HD map 矢量对齐，目标函数怎么构造？异常匹配（施工改道）如何检出？

**参考答案要点**：常见为点到线/点到面距离 + 朝向一致性 + 拓扑约束；鲁棒损失（Huber/Cauchy）+ RANSAC/一致性检验；与 lane / curb 几何关联；异常靠残差突变、多假设匹配或多传感器不一致剔除。

#### Q8. 自动标注产线可用率 >99%：如何定义「可用」？如何保证高速 10 万 km 规模的质量控制？

**参考答案要点**：可用 = 位姿精度阈值内 + 标注完整性 + 无跳变；QC 靠抽样评测、规则校验（轨迹连续性、与地图一致性）、监控 dashboard；追问具体阈值与 bad case 回流。

### D. 地平线：记忆泊车 HPA（2023.09–2024.07）

#### Q9. 初始化 / 地图匹配 / 对齐：停车场重复结构多，如何减轻「匹配错层、错车位」？你提到的绝对定位模式与地图选择错误的根因与解法？

**参考答案要点**：多假设跟踪、几何一致性（高度层、柱子间距）、语义（车位号若可用）、惯性短时积分淘汰不一致假设；绝对模式可能引入 GNSS/指纹/入口锚点（视场景）；地图选择错误靠候选地图打分 + 持续校验残差。

#### Q10. 定位校正：是闭环检测 + 全局 pose 修正，还是局部 map-based 重定位？延迟与用户体验如何平衡？

**参考答案要点**：可能是片段式全局对齐或关键帧库重定位；需限制突变（平滑过渡）、触发条件（残差超阈、匹配分数低）；用户体验上避免频繁跳变。

### E. 华捷艾米：VIO / 协同 SLAM（2019–2021）

#### Q11. VINS-RGBD 上加特征均匀化的具体做法？对优化可观性有何帮助？

**参考答案要点**：网格化图像分桶、每桶保留最强响应特征，抑制扎堆；改善旋转估计与三角化几何分布，减轻病态方向。

#### Q12. 2-Point RANSAC 相对经典本质矩阵 5-point / 基础矩阵 8-point：前提是什么？在 RGBD 下如何利用深度？

**参考答案要点**：2-point 通常需已知平面或已知旋转（或其它约束）；若有深度可削弱尺度/结构模糊或减少采样维度——追问简历中的具体假设是否平面运动或已知重力对齐旋转。

#### Q13. CCM-SLAM + gRPC/Protobuf：中心化瓶颈在哪（带宽、延迟、单点故障）？多机地图如何融合？

**参考答案要点**：服务器负载、网络抖动、时钟同步；地图融合可能是全局 pose graph + 关键帧上传或子图合并；追问一致性协议与冲突处理。

## 二、针对 SLAM 算法提问

（候选人资历深，题可偏设计与权衡，而非定义背诵。）

#### Q16. MSCKF 与基于优化的 VIO（如 VINS）在观测处理上的本质区别？何时仍会用 MSCKF？

**参考答案要点**：MSCKF 边缘化特征只保留 pose 递推，特征多视图约束经投影压缩；优化方法保留滑窗内特征联合优化。MSCKF 计算预算紧、需要严格 FEJ 等防不一致；优化精度高、实现灵活。

#### Q17. First-Estimates Jacobian（FEJ）解决什么问题？不用会怎样？

**参考答案要点**：固定线性化点避免错误信息注入不可观方向导致虚假可观测；不用可能出现尺度或 yaw 漂移类数值问题（依赖具体参数化）。

#### Q18. 轮速计在融合模型中的可观性：单独轮速+IMU 哪些方向弱？视觉/LiDAR 如何补？

**参考答案要点**：平面运动侧滑不可观、尺度与绝对 yaw 弱；视觉/LiDAR 提供横向约束与全局对齐。

#### Q19. RTK 浮动解 vs 固定解在滤波器里如何处理（噪声模型切换、模糊度固定事件）？

**参考答案要点**：切换协方差或 Switching factors；固定解收紧位置观测；浮动解用较大噪声或降权避免拉偏。

#### Q20. LOAM / LIO-SAM / FAST-LIO 三类 LiDAR 里程计思路差异一句话概括？

**参考答案要点**：LOAM 边缘/平面特征扫描匹配；LIO-SAM 因子图 + scan-to-map + IMU 预积分；FAST-LIO 迭代卡尔曼 + 直接点云残差（典型 ikfom）。

#### Q21. COLMAP / SFM 与 SLAM 前端特征选择的差异（为何 SLAM 更重跟踪、SFM 更重几何精度）？

**参考答案要点**：SLAM 要实时、均匀分布、鲁棒短期跟踪；SFM 可离线选点多视图强几何。

#### Q22. 3DGS 作为「地图」与传统点云/TSDF 在定位或仿真闭环里的优缺点？

**参考答案要点**：GS 渲染逼真、显式表达场景外观；几何度量性、编辑一致性、动态物体分离仍是痛点；仿真闭环看重渲染速度与可控动态物体。

#### Q23. 如何离线评测多传感器融合定位（ATE/RPE、车道级指标、GNSS 遮挡段）？

**参考答案要点**：RTK/激光轨迹真值或 post-processing；分段统计；引入卫星遮挡与隧道场景；evo 类工具。

## 三、C++ 编程能力考核（语法与惯用法）

#### Q24. `std::unique_ptr` 与 `std::shared_ptr` 分别在 SLAM 工程里典型用在什么对象上？`shared_ptr` 的性能代价在哪？

**参考答案要点**：unique 拥有独占资源（订阅者少）；shared 用于多模块共享地图块/缓冲；代价为原子引用计数与控制块。

#### Q25. 下面代码是否有问题？说明原因。

```cpp
Eigen::Matrix4d T;
SomeFunc(T.data());  // SomeFunc takes double* and writes 16 doubles
```

**参考答案要点**：需确认 `Eigen::Matrix4d` 是否 16 字节对齐、`Map`/指针接口是否期望行主序；直接 `.data()` 若接口假设列主序可能错位；对齐问题在 SIMD 类型与 ABI 边界需注意。

#### Q26. `virtual ~Base() = default;` 与「非虚析构」在 `delete Base* p = new Derived` 下的区别？

**参考答案要点**：非虚析构 → 未定义行为（Resource leak）；多态基类应虚析构。

#### Q27. `std::move` 后继续使用被移动对象要注意什么？

**参考答案要点**：对象处于有效但未指定状态；仅允许赋值或析构等安全操作；禁止假设值不变。

#### Q28. `constexpr` 与 `const` 区别；`if constexpr` 解决什么问题？

**参考答案要点**：constexpr 编译期常量（C++11/14/17 规则递增）；if constexpr 避免模板实例化无效分支。

#### Q29. `std::vector<Foo>` 中 `Foo` 含 `std::mutex`，能否编译通过？正确做法？

**参考答案要点**：mutex 不可移动不可拷贝，vector 要求元素至少可移动赋值；应 `vector<unique_ptr<Foo>>` 或 `deque`/自定义容器。

#### Q30. 多线程：`*ptr = ...` 与 `ptr->fetch_add`（`atomic<int>`）可见性差异？

**参考答案要点**：普通指针写需 mutex 或 atomic/内存序保证；`atomic` 提供定义良好的原子性与顺序（memory_order）。

#### Q31. `emplace_back` vs `push_back`？

**参考答案要点**：emplace 原位构造避免临时对象；类型推导与异常安全略需注意。

#### Q32. `std::bind` 与 lambda 在现代 C++ 中的取舍？

**参考答案要点**：lambda 更清晰、易内联；bind 易类型推断坑；新项目偏好 lambda。

#### Q33. `explicit` 构造函数避免什么？

**参考答案要点**：避免隐式单参数转换导致的意外临时对象。

#### Q34. CRTP 相比虚函数在性能敏感路径上的利弊？

**参考答案要点**：CRTP 静态多态、无虚调开销；代码膨胀、接口不够灵活。
