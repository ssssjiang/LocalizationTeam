## 2. 现象(Confirmed facts)

依据日志 `000321` + 现场视频(李欢 / 李升文 12/10)：

1. 退桩出基站，机器进入"出桩遮挡自检"状态
2. 旋转 180° 后机器静止(不再行进，不继续旋转推进检测)
3. 遮挡检测 2min 超时结束，期间未收敛
4. app 无错误码上报(用户视角 = 卡困停机但毫无提示)
5. 遮挡双目后视觉避障误检 — 类物体、泛物体均出现(来源：李欢 12/10 视频复盘)

---

## 3. 根因假设(High-confidence judgment)

**死循环链**(来源：李哲分析)：

```
路程未走够 → 遮挡检测未收敛 → 未上报"已遮挡"
        ↓                                ↑
导航停机 ← 视觉避障误检(类/泛物体) ← 视野被遮挡
```

逐环说明：

1. D-017 出桩自检算法依赖**一定旋转 + 一定路程**多帧梯度均值 / 像素亮度变化判别
2. 检测未完成 → 定位侧不上报"已遮挡"状态
3. 但**视野已实际被遮挡** → 感知输出大量虚假障碍物(类 / 泛物体)
4. 导航默认信任视觉障碍物 → 停机
5. 机器静止 → 路程不再增长 → 回到 1，直到 2min 超时

**仍需会上核实的关键点**：

- Q1(感知)：遮挡 → 视觉障碍物误检的因果是否在所有遮挡严重度下都成立
- Q2(导航)：视觉障碍物结果是否有现成的去抖 / 置信度过滤
- Q3(定位 / 测试)：4 次中 1 次播报的差异条件(光照 / 纹理 / 材质？)

## 4. 候选方案

| 方案    | 改动方 | 内容                                | 优点              | 风险                                          |
| ----- | --- | --------------------------------- | --------------- | ------------------------------------------- |
| **A** | 感知  | 出桩自检阶段，感知不输出视觉障碍物结果               | 闭环干净，断根因        | 需自检状态信号；自检期间真有障碍物会漏检(需评估安全边界)              |
| **B** | 导航  | 出桩自检期间，导航不信任视觉障碍物(仍信任激光等其他源)      | 感知策略不动，导航策略层兜底  | 同样需自检状态信号；需确认其他障碍源足够安全                      |
| **C** | 不修  | 维持现状(李哲倾向) — 用户体验上"遮挡停机"和"卡困停机"等价 | 无改动成本           | **单建强 04-16 已明确反对**：草丛 / 窄通道场景下死循环风险不可接受    |
| **D** | 定位  | 静止 N 秒且路程不推进 → 主动失败上报错误码          | 至少消除"无声卡 2min" | 不解根因；仅把"无声卡困"变成"有错码停机"                     |

**倾向**：**A 或 B**(解根因) + **D**(兜底防静默)。
**C 不可接受**：单建强已明确反对，且草丛 / 窄通道场景同源风险存在。
