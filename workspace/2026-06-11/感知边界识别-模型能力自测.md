# 感知边界识别 — 模型能力自测

> **定位**：感知组（蔡利冰）对边界识别**模型能力**的自测，与导航/插件的逻辑·状态·时序白盒（见 `自主沿边-研发自测白盒用例.md`）互补。
> **本质**：测的是模型「认得准不准、测得精不精、漏不漏、抗不抗干扰」，不是代码分支逻辑。
> **要求**：每条「测试项 → 操作步骤 → 期望结果」三元素俱全；覆盖 **类别正确性 / 精度 / 召回 / 鲁棒性 / 实时性 / 已知短板**。
> **数据基线**：期望值引用 `00-自主沿边-信息总览与矛盾点.md` §2（11 月模型实测）与 PDD 性能指标；冲突项见 §9。

## 0. 范围与约定

### 0.1 测什么 / 不测什么

- **测**：齐平(可跨/不可跨)、高墙(实心/镂空/网状)、植被景观、水池/水面的**识别类别 + 测距精度 + 召回 + 鲁棒性**。
- **不测（归导航白盒）**：跌落边界检测（设计上**由导航负责检测**，非感知）；边界类型滤波/保存/沿边策略。
- **本期算法主关注**：齐平(可跨) + 水池（+ 跌落由导航）；高墙/植被为次优先级。

### 0.2 维度标签

`类别`=识别类别正确 / `精度`=测距/定位误差 / `召回`=覆盖率漏检 / `鲁棒`=干扰下不崩 / `实时`=延迟帧率 / `短板`=已知能力边界验证。

### 0.3 指标基线（期望值参考，记录实测对比）

- 点云测距精度（分距离段，11 月模型）：0–0.2m **0.36cm** / 0.4–0.6m **1.27cm** / 0.8–1.0m **3.15cm** / 1.2–1.5m **5.4cm** / 1.5–2.0m **9.44cm** / 0–2.0m 均值 **1.92cm**。
- 沿边专项精度（10cm 距离）：双墙 0.92 / 水泥墙 1.06 / 鹅卵石 1.24 / 石板砖瓷砖 1.2–1.4 / 镂空铁栅栏 1.48 / 树篱 2.13 / 泳池 3.60（cm）。
- 分割 mIoU：草 0.98 / 栅栏 0.91 / 路面 0.91 / 植物 0.81 / 水面 0.78 / 泥地 0.66 / 落叶 0.64（均 0.82）。
- 检测 mAP50：喷头 0.99 / 桩 0.99 / 刺猬 0.97 / 宠物 0.95 / 小水坑 0.93 / 人 0.92 / 线状 0.91。
- PDD 目标：识别误差 ≤±1cm（`[争议]` 见 §9）；延迟 ≤100ms；帧率 ≥5fps；覆盖率 标准边界 ≥99% / 模糊边界 ≥95%；光照 5lux–100000lux；雨天 IPX5 ≥95%。

## 九、待确认（影响期望取值）

- `[争议]` **±1cm 识别精度**：PDD 目标 ≤±1cm，但研发明确**给不出**，且**点云测距精度 ≠ 沿边精度**（缺分割像素误差叠加）。6/9 当面定「感知层精度估算方法」（几何推算 vs 大量实测）。本文期望先以「记录实测 + 对齐基线」处理，不把 ±1cm 当硬门槛。
- `[归属]` 跌落边界由**导航检测**，不在本感知自测内；高度阈值口径（PDD 2cm/5cm、跌落算法 6cm）需与导航统一。
- `[依赖]` P-34 插件实时打印三级类别是否实现，需跟李升文/奚学华。
- `[范围]` 本期主关注齐平(可跨)+水池；高墙/植被为次优先级，精度门槛可放宽。
