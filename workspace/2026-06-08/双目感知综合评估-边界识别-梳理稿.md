# 双目感知综合评估 梳理稿（边界识别相关）

**来源**：`双目点云、检测、分割综合评估方案_20260608_105652.md`

---

## 核心结论

双目感知对规则硬质边界（墙/路沿/石板路等）的点云精度和分割识别已基本满足沿边需求；**镂空结构（细栅栏）、不规则结构（树篱）、以及落叶/稀疏草地/阴影等干扰类场景仍是当前的主要薄弱点**，均有对应 finetune 计划。

---

## 一、点云质量（3D）

### 1.1 核心指标

- 点云误差对比对象：感知小模型 vs FDS 大模型点云（非雷达点云）
- 测距范围：机器从 2.0m 前进到 0.15m，逐帧计算 0.15m~2.0m 内点云平均欧式距离

| 模型 | 全程平均误差 | 视差 EPE |
| --- | --- | --- |
| 9 月 Baseline | 1.90cm | 1.76 |
| 11 月 New model | 1.92cm | 1.21 |

### 1.2 草坪边界沿边场景（直接相关）

> **评估要点**：连续侧边障碍物的点云稳定性

**结论**：规则障碍物效果好；细物体/不规则物体有轻微波动；边界被草遮挡时点稀少。

| 沿边场景 | 精度(cm) | 小结 |
| --- | --- | --- |
| 水泥墙沿边 10cm | 1.061 | 完整，无拉丝 |
| 双墙面沿边 10cm | 0.922 | 完整，无拉丝 |
| 石板路沿边 10cm | 1.250 | 完整，无拉丝 |
| 鹅卵石路沿边 10cm | 1.240 | 完整，无拉丝 |
| 砖石路沿边 10cm | 1.331 | 完整；草遮挡时边界点稀少 |
| 瓷砖路沿边（高于） | 1.428 | 完整，无拉丝 |
| 瓷砖路2沿边（齐平） | 1.233 | 完整，无拉丝 |
| 红砖路沿边 | 1.308 | 完整，无拉丝 |
| 镂空铁栅栏沿边 10cm | 1.479 | 完整；**单根细杆有轻微波动** |
| 树篱沿边 10cm | 2.131 | 完整；**点云有轻微抖动** |
| 泳池沿边 10cm | 3.601 | 稳定；**轻微拉丝；草遮挡时边界点稀少** |

**改进计划**：增加细物体场景、不规则物体场景数据；针对 bug 场景专项优化。

### 1.3 其他挑战场景关键结论

| 场景类型 | 结论 | 改进计划 |
| --- | --- | --- |
| 镂空/悬空结构 | 前后景点云易粘连；极细铁丝网难以识别 | 增加镂空/悬空场景 finetune |
| 细长物体 | 点云无法保持直线一致，密度低 | 增加细长物体数据 finetune |
| 弱纹理/重复纹理 | 效果较好，无需优化 | — |
| 反光/透明（水潭/玻璃） | 水潭无法感知；玻璃只能感知背后物体 | 增加反光场景数据；结合分割检测水坑 |
| 弱光（傍晚/夜间） | 点云波动大，不稳定 | 增加弱光场景数据 |
| 强光过曝 | 过曝区域点云失效；过曝阴影会误识别成障碍 | 增加过曝和过曝阴影数据 |
| 高草遮挡 | 近前高草点云混乱，影响边界感知 | 增加高草场景数据 finetune |

### 2.2 沿边场景专项测试（真机采集）

> 通过遥控机器真实运动采集沿边数据（分割图 + 点云图 + 边界图三联帧）

**结论**：在不同天气的栅栏、石板路、灌木场景下，分割模型表现稳定；**连续 15 帧（约 2 秒）可稳定识别边界**（算法处理帧率 7.5fps）。

**待优化项**：
- 竖形翘起的落叶识别较差（平躺椭圆形落叶较好）
- 阳光直射下椅子腿误识别为草
- 黑色物体在部分条件下识别不准
- 机器旋转时假草坪识别待优化（低优先级）

### 2.3 分割避障风险项（影响沿边通行的已知问题）

> **当以分割模型为主时（非草即障碍），以下场景机器均无法正常通行；利用点云高度信息可规避部分风险**

| 风险类型 | 问题描述 | 规避手段 |
| --- | --- | --- |
| **落叶** | 多片连接的落叶有概率被识别为障碍，草地中大量出现 | 结合点云高度信息 |
| **稀疏草地/泥土** | 泥土属非草，被识别为障碍，影响通行 | 结合点云高度信息 |
| **悬空障碍物** | 障碍物底部为草，分割无法避障，会碰撞 | 结合点云识别 |
| **阴影** | 阴影区域草有概率误判为障碍 | 需持续优化 |
| **枯草/黄草** | 数据少，与绿草差别大，有概率误判为障碍 | 需持续优化 |
| **草地中的植物/地灯** | 属于非草，造成避障影响通行 | 结合语义类别过滤 |

## 三、目标检测（与边界识别相关性低，概要）

7 类检测（人/宠物/刺猬/地埋喷头/线状物/小水坑/充电桩），mAP50 全类平均 0.657。

**导航要求**：至少在机器前 30cm 处检到。满足该要求的类别：人、宠物、刺猬（≥1.0m）、喷头、充电桩。**不满足**：展开电线（仅靠近时检到部分）、展开水管、小水坑（傍晚完全漏检）。

## 与自主沿边的对应关系

| 自主沿边需求 | 感知当前能力 | 薄弱点 |
| --- | --- | --- |
| 规则硬质边界测距（墙/路/砖石） | ✅ 精度 ~1-1.5cm，稳定 | 草遮挡时边界点稀少 |
| 镂空结构（栅栏） | ⚠️ 细杆轻微波动，粘连问题 | 极细铁丝网失效 |
| 不规则/植被边界（树篱/灌木） | ⚠️ 轻微抖动，mIoU 0.81 | 数据待增补 |
| 水体边界（泳池） | ⚠️ 轻微拉丝，草遮挡时点稀 | — |
| 弱光/傍晚沿边 | ❌ 点云不稳定，分割需增强 | 需加数据增强 |
| 高草遮挡边界 | ❌ 点云混乱 | 需 finetune |
