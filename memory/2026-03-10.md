### 3. ClawHub 限流诊断与修复（最终解决）
- **诊断过程**：
  - CLI 层：能登录、whoami 正常，但 search/explore 持续限流
  - 网络层：clawhub.ai 网站 HTTP 200，但 api.clawhub.ai 的 TLS 握手失败（EOF）
  - 根因：Clash Verge（Mihomo）的 DNS 将 api.clawhub.ai 解析到 fake IP（11.18.0.x），导致 TLS 失败
- **修复方案（最终生效）**：在 Clash Verge GUI 的 DNS 配置里，将 `*.clawhub.ai` 加入 `fake-ip-filter`
  - 路径：Clash Verge GUI → DNS 设置 → fake-ip-filter 配置
  - 作用：让 clawhub.ai 走真实 DNS 而不是 fake IP
  - 结果：clawhub search 现在可以正常工作 ✅
  - 优势：此方法通过 GUI 配置，更稳定，不会被 profile 覆盖
- **之前尝试的不足方案**：
  - 文件编辑 DIRECT 规则：DNS 劫持太激进，规则无效
  - 结论：fake-ip-filter 在这个 Mihomo 配置下更有效
